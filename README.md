# Expense Tracker

A modern Flutter application for tracking expenses and income with clean architecture, interactive analytics charts, and local SQLite persistence.

## Features

- **Dashboard Overview**: Total balance, income, and expense summary cards.
- **Transactions Management**: Add, edit, delete, and filter transactions.
- **Analytics & Charts**: Category breakdown and spending distribution.
- **Local Database**: Offline-first persistence using SQLite (sqflite).
- **Themes**: Modern UI with Material 3 design and dark/light mode support.

## Getting Started

1. Ensure you have Flutter installed:
   ```bash
   flutter --version
   ```

2. Install dependencies:
   ```bash
   flutter pub get
   ```

3. Run the application:
   ```bash
   flutter run
   ```
